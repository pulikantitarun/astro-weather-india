# Contributing

Contributions are welcome through GitHub issues and pull requests.

## Before submitting

1. Keep changes compatible with the AGPL-3.0-or-later licence.
2. Do not commit Wi-Fi credentials, tokens, compiled build folders or personal
   configuration.
3. Preserve the attended-imaging safety warning.
4. Document physical dimensions for any newly supported sensor board.
5. Validate edited STL files and describe any physical print testing performed.
6. For firmware changes, build the PlatformIO project before opening a PR.

Mesh validation does not establish real-world fit or outdoor safety. Clearly
separate digital validation from physical test results.
